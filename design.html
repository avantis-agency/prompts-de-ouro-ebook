Prompts de Ouro:
Design & Cores.

Os scripts exatos para forçar a IA a agir como o Squad 'Proposta-Magnética' e gerar orçamentos interativos nível Awwwards.

O Segredo da Orquestração

A inteligência não está em pedir um código, mas sim em invocar a "mente" certa da IA. Ao usar esses prompts, você aciona o comportamento do Squad Proposta-Magnética (ou Fábrica-Landing-Pages), que possui o DNA do design brutalista.

Prompt 1: A Invocação do Squad & Chassi Visual

Esse é o comando raiz. Ele trava o cérebro da IA na estética correta e conecta as tipografias de luxo.

"A partir de agora, assuma a mente e a autoridade do agente 'Diretor de Design' do squad 'proposta-magnetica'. Sua missão é gerar o HTML/CSS de uma proposta comercial.

A fundação visual deve seguir ESTRITAMENTE estas conexões de design:
1. Fundo dark brutalista (ex: #050505) com radial-gradients sutis nos cantos.
2. Tipografia Híbrida: Use Google Font 'Fraunces' (Serif) exclusiva para os títulos (H1, H2) e 'Inter' (Sans-Serif) para o corpo.
3. Layout fluido usando CSS clamp() — NUNCA use media queries fixas para font-size.
4. Esconda o ponteiro do mouse padrão e injete um .cursor-dot interativo."

Prompt 2: Engenharia de Cores (O Sistema OKLCH)

O segredo para cores que se casam perfeitamente. Nunca deixe a IA adivinhar o hexadecimal.

"Atuando como o Diretor de Design do squad, vamos definir a paleta de cores. A cor primária da marca do meu cliente é [INSERIR COR, ex: #FF4500].

Esqueça o sistema RGB padrão. Converta essa cor e gere uma paleta matemática utilizando o sistema OKLCH.
- Crie 3 tons neutros (1 escuro para fundo, 1 médio para bordas, 1 claro translúcido para textos).
- Crie 1 cor de destaque (Accent) baseada na cor primária com alta saturação para os botões e CTAs.
Gere as variáveis CSS Custom Properties no escopo :root para que todas as cores conversem entre si."

Prompt 3: A Tabela de Orçamento Magnética

Transforma o preço de uma "despesa" em um item de prateleira de luxo.

"Agora invoque a mente do agente 'Engenheiro Front-End' do squad. Precisamos codar a seção de Orçamento.

Crie um CSS Grid assimétrico (ex: 2fr 1fr). O lado esquerdo terá os itens do escopo, e o lado direito terá os valores em destaque.
Regras de Interação e Cores:
- Use a paleta OKLCH que geramos. O fundo da tabela deve ser um vidro translúcido (Glassmorphism sutil).
- Adicione um efeito de hover magnético nos preços: quando o mouse (.cursor-dot) passar por cima, faça o card ganhar escala e injete um sutil 'box-shadow' usando a cor de destaque (Accent).
- O contraste deve atender aos padrões APCA, garantindo que o valor financeiro brilhe na tela."

Prompt 4: Scroll-Driven Motion (Efeito Cinematográfico)

O que faz o cliente dizer "WOW". Revele o conteúdo conforme ele rola a página, sem JavaScript pesado.

"Para finalizar, atue como o Animador do squad. Queremos um efeito de revelação ao scrollar a página para a Metodologia e os Preços.

Restrição Técnica Obrigatória: Não use bibliotecas (GSAP, Lenis) ou JavaScript. Use puramente CSS Nativo com '@supports (animation-timeline: view())'.
As seções devem começar com 'opacity: 0' e 'transform: translateY(40px)', e revelar gradativamente enquanto entram na viewport, garantindo um fluxo cinematográfico e leve."
