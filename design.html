Prompts de Ouro:
Awwwards Engine.

14 Scripts de orquestração para forçar a IA a gerar orçamentos estáticos no padrão Dark SaaS (prontos para Surge.sh).

Fundação & Infraestrutura

Prompt 1: A Invocação do Squad & Chassi Visual

O comando raiz. Trava a mente da IA na estética Dark SaaS correta e conecta as tipografias.

"A partir de agora, assuma a autoridade do 'Diretor de Design' do squad 'proposta-magnetica'. Sua missão é gerar o HTML/CSS de uma proposta comercial.

A fundação visual deve seguir ESTRITAMENTE estas diretrizes:
1. Fundo dark profundo (#030B08) com radial-gradients sutis emitindo glows rosa neon (#EF5FA5).
2. Tipografia 'General Sans' ou 'Outfit' (Sans-Serif geométrica) para todo o documento, com letter-spacing negativo (-0.03em) para os títulos.
3. Layout fluido usando CSS clamp().
4. Esconda o ponteiro do mouse padrão e injete um .cursor-dot interativo rosa neon."

Prompt 2: Restrição de Deploy (Surge.sh / GitPages)

"Atenção para a infraestrutura de deploy: Esta proposta comercial será hospedada estaticamente usando o Surge.sh (ou GitHub Pages). É PROIBIDO usar bundlers (Webpack/Vite), React, Next.js ou backend.

Entregue apenas 'index.html', 'styles.css' e 'script.js'. Dependências de fontes e bibliotecas de estilo via CDN."

Prompt 3: Engenharia de Cores (O Sistema OKLCH)

"A cor primária de destaque (Accent) da nossa proposta será o Neon Magenta (#EF5FA5).

Esqueça o sistema RGB padrão. Converta essa cor e gere uma paleta matemática utilizando o sistema OKLCH.
- Crie tons neutros profundamente escuros para o fundo.
- Crie bordas sutis translúcidas (Glassmorphism).
- O texto deve ser branco gelo (#ffffff) para contraste máximo."

Layouts & Componentes

Prompt 4: O Grid "Bento Box" de Serviços

"Crie a seção 'O Escopo'. Ao invés de uma lista, construa um layout 'Bento Box' usando CSS Grid nativo.

Regras:
1. Cards assimétricos (ex: um ocupando duas colunas, outros ocupando uma).
2. Efeito 'Glassmorphism': fundo escuro translúcido, backdrop-filter: blur(12px) e borda de 1px sólida translúcida.
3. Ícones ou detalhes em Magenta Neon (#EF5FA5)."

Prompt 5: A Tabela de Orçamento Magnética

"Codifique a seção de Orçamento.

Crie um CSS Grid assimétrico (2fr 1fr). O lado esquerdo terá os itens, e o direito os valores.
Regras:
- Efeito de hover magnético: quando o cursor passar por cima do preço, injete um brilho sutil (box-shadow neon) usando a cor Accent.
- Os valores financeiros devem brilhar na tela com tipografia encorpada."

Prompt 6: Ticker Tape Infinito (Marquee)

"Adicione uma quebra visual criando um 'Infinite Marquee'.

Regras:
1. Uma faixa de ponta a ponta na tela, sem fundo, com bordas magenta sutis superior e inferior.
2. O texto será 'HIGH-END DESIGN • DIGITAL PRESENCE • LUXURY'.
3. Use CSS Keyframes (transform: translateX) para animar. Não use JavaScript."

Prompt 7: O Menu Mobile Fullscreen (Dark Overlay)

"Construa a navegação mobile.

Quando o cliente clicar no 'Menu', a tela inteira deve ser coberta por um overlay escuro (backdrop-filter pesado) com transição suave. Os links devem aparecer gigantes e centralizados. O hover nos links deve deixá-los com a cor magenta (#EF5FA5)."

Micro-Interações e Motion

Prompt 8: Scroll-Driven Motion (Nativo)

"Queremos um efeito de revelação ao scrollar a página.

Restrição: Não use JavaScript. Use puramente CSS Nativo com '@supports (animation-timeline: view())'.
Os painéis em glassmorphism devem começar com 'opacity: 0' e 'transform: translateY(40px) scale(0.95)', e revelar gradativamente enquanto entram na viewport."

Prompt 9: O Cursor Interativo nos Botões

"Melhore a interação do '.cursor-dot'. Adicione um script JS leve que escute os eventos de 'mouseenter' e 'mouseleave' nos botões e links.

Ao passar sobre um link, o .cursor-dot deve aumentar de tamanho (scale 3) e o box-shadow magenta deve ficar mais agressivo, criando um hover magnético de alto padrão."

Prompt 10: Texto de Revelação (Text Reveal)

"Aplique um 'Text Reveal Animation' no H1 da Hero section.

Separe o H1 usando tags span com 'overflow: hidden'. O texto interno deve sofrer um 'transform: translateY(100%)'. Ao carregar a página, as palavras deslizam de baixo para cima sequencialmente (stagger), durando 1 segundo."

Finalização e Limpeza

Prompt 11: O Preloader Minimalista

"Crie uma tela de Loading que dura 1.5 segundos antes de mostrar o site.

A tela deve ser escura (#030B08). No centro, mostre uma contagem de 0% a 100% carregando, usando a cor magenta. Ao atingir 100%, o preloader deve deslizar para cima, revelando o dashboard brutalista."

Prompt 12: O Footer "Manifesto"

"Esqueça rodapés tradicionais. Crie um Footer 'Manifesto' ocupando 100vh.

Regras:
1. Uma frase final de impacto em tamanho Colossal (clamp(4rem, 15vw, 12rem)), com tracking negativo apertado.
2. Botão neon brilhante para fechar negócio.
3. Botão secundário de 'Baixar Proposta' (window.print())."

Prompt 13: Refinamento Tipográfico

"O design precisa de refino SaaS.

1. Alinhamento seco à esquerda.
2. Aumente o H1 para 'clamp(3rem, 10vw, 8rem)'.
3. Zere o letter-spacing (0%) ou torne-o negativo (-0.03em) para os títulos ganharem um visual condensado corporativo."

Prompt 14: Filtro Anti-Slop de Código

"Releia o código gerado e remova:
- Divs desnecessárias.
- Sombras cinzas pesadas. Troque todas por glows com a cor Magenta Neon em baixíssima opacidade (0.05).
- Confirme se não há quebras para hospedar no Surge.sh."
