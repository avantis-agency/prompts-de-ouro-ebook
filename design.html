Os scripts exatos para forçar a Inteligência Artificial a transformar esboços chatos em propostas interativas nível Awwwards.

O Segredo do Design Agêntico

A maior dificuldade de quem compra a Proposta Magnética é abrir o ChatGPT/Claude e pedir "Crie um design bonito". A IA sempre vai cuspir um layout branco com cara de Bootstrap de 2015. Para extrair a estética Dark Brutalism, você precisa hackear os parâmetros visuais da IA. Use os prompts abaixo.

Prompt 1: O Chassi Awwwards (Fundação)

Esse é o comando que você roda logo no início para travar o cérebro da IA na estética correta.

"Atue como um Desenvolvedor Front-End de Elite de um estúdio premiado no Awwwards. Eu vou te passar o esboço de uma proposta comercial e você vai codar uma página HTML single-file para ela.

A fundação visual (O Chassi) deve seguir ESTRITAMENTE estas regras:
1. Fundo dark brutalista (ex: #050505) com radial-gradients sutis nos cantos.
2. Tipografia Híbrida: Google Font 'Fraunces' para os títulos (H1, H2) e 'Inter' para o corpo do texto.
3. Sem breakpoints fixos: Use CSS clamp() para toda a tipografia.
4. Esconda o cursor do mouse padrão e crie um .cursor-dot invertido.

Inicie gerando o HTML/CSS base do esqueleto da página seguindo essa estética."

Prompt 2: A Tabela de Orçamento Interativa

O momento de ancorar o preço. Transforma uma tabela de PDF morta em uma precificação de luxo.

"Agora vamos criar a seção de Orçamento/Escopo. Esqueça tabelas tradicionais e chatas.

Crie um CSS Grid assimétrico (ex: 2fr 1fr). O lado esquerdo terá os itens do escopo, e o lado direito terá os valores em destaque.
Regras de Interação:
- Adicione um efeito de hover magnético (leve ganho de escala e brilho na borda) quando o mouse passar por cima da caixa de preço.
- Use a cor branca brilhante para os valores, e um cinza translúcido para as descrições.
O objetivo é fazer o preço parecer um item de luxo dentro de um card de vidro escuro."

Prompt 3: Scroll-Driven Motion (Efeito Cinematográfico)

O que faz o cliente dizer "WOW". Revele o conteúdo conforme ele rola a página, sem usar JavaScript pesado.

"Para as seções de 'Nossa Metodologia' e 'Estudo de Caso', quero um efeito de revelação ao scrollar a página.

Restrição Técnica Obrigatória: Não use bibliotecas como GSAP, Lenis ou JavaScript para isso. Use puramente CSS Nativo com '@supports (animation-timeline: view())'.

A animação deve ser sutil: as caixas de conteúdo devem começar com 'opacity: 0' e 'transform: translateY(40px)', e revelar gradativamente enquanto entram na viewport do cliente. Crie esse bloco de CSS e aplique nas seções."

Prompt 4: O Refinamento de Tipografia (Anti-Bootstrap)

Quando a IA insiste em alinhar tudo ao centro e usar fontes genéricas, solte esse comando.

"O design está ficando com cara de template genérico. Pare e reajuste as regras de tipografia:

1. Remova todos os 'text-align: center'. O design brutalista exige alinhamentos secos à esquerda.
2. Aumente drasticamente o tamanho do H1 (use clamp(3rem, 10vw, 8rem)). O título tem que gritar na tela.
3. Aumente o tracking (letter-spacing) nas tags (subtítulos menores em caps lock).
4. Garanta que a fonte serifada (Fraunces) esteja sendo aplicada com font-weight 300 (bem fina e elegante)."
