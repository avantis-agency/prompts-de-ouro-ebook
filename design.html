Prompts de Ouro:
Awwwards Engine.

14 Scripts de orquestração para forçar a IA a gerar orçamentos interativos e estáticos, prontos para subir no Surge.sh ou GitHub Pages.

Fundação & Infraestrutura

Prompt 1: A Invocação do Squad & Chassi Visual

O comando raiz. Trava a mente da IA na estética correta e conecta as tipografias de luxo.

"A partir de agora, assuma a mente e a autoridade do agente 'Diretor de Design' do squad 'proposta-magnetica'. Sua missão é gerar o HTML/CSS de uma proposta comercial.

A fundação visual deve seguir ESTRITAMENTE estas conexões de design:
1. Fundo dark brutalista (#050505) com radial-gradients sutis.
2. Tipografia Híbrida: Google Font 'Fraunces' (Serif) exclusiva para os títulos e 'Inter' (Sans-Serif) para o corpo.
3. Layout fluido usando CSS clamp().
4. Esconda o ponteiro do mouse padrão e injete um .cursor-dot interativo."

Prompt 2: Restrição de Deploy (Surge.sh / GitPages)

Garante que a IA não invente servidores Node.js ou código impossível de hospedar grátis.

"Atenção para a infraestrutura de deploy: Esta proposta comercial será hospedada estaticamente usando o Surge.sh (ou GitHub Pages). Portanto, é ESTRITAMENTE PROIBIDO usar bundlers (Webpack/Vite), React, Next.js ou qualquer linguagem de backend.

Entregue apenas arquivos 'index.html', 'styles.css' e 'script.js' (ou um single-file HTML). Qualquer dependência externa (como fontes ou bibliotecas de animação) deve ser importada obrigatoriamente via CDN (tag script ou link)."

Prompt 3: Engenharia de Cores (O Sistema OKLCH)

"Atuando como o Diretor de Design, vamos definir a paleta de cores. A cor primária do meu cliente é [INSERIR COR, ex: #FF4500].

Esqueça o sistema RGB padrão. Converta essa cor e gere uma paleta matemática utilizando o sistema OKLCH.
- Crie 3 tons neutros (escuro para fundo, médio para bordas, claro para textos).
- Crie 1 cor de destaque (Accent) baseada na cor primária com alta saturação para os CTAs.
Gere as variáveis CSS Custom Properties no escopo :root."

Layouts & Componentes

Prompt 4: O Grid "Bento Box" de Serviços

Acaba com a lista de bullets feia e transforma os serviços em um mosaico premium.

"Crie a seção 'O Escopo'. Ao invés de uma lista chata, construa um layout estilo 'Bento Box' usando CSS Grid nativo.

Regras:
1. Os cards devem ter tamanhos assimétricos (ex: um card ocupando duas colunas, outros ocupando uma).
2. Aplique um efeito 'Glassmorphism' em cada card: fundo translúcido (rgba), backdrop-filter: blur(12px) e uma borda de 1px sólida com 10% de opacidade.
3. O conteúdo interno deve ter respiro gigante (padding de 2rem)."

Prompt 5: A Tabela de Orçamento Magnética

"Agora invoque a mente do 'Engenheiro Front-End' do squad. Precisamos codar a seção de Orçamento.

Crie um CSS Grid assimétrico (2fr 1fr). O lado esquerdo terá os itens, e o direito os valores.
Regras de Interação:
- Use a paleta OKLCH que geramos.
- Efeito de hover magnético nos preços: quando o mouse (.cursor-dot) passar por cima, faça o card ganhar escala e injete um sutil 'box-shadow' usando a cor Accent.
- O contraste deve atender aos padrões APCA."

Prompt 6: Ticker Tape Infinito (Marquee)

A famosa faixa de texto correndo pela tela, marca registrada de sites Awwwards.

"Adicione uma quebra visual entre a Metodologia e o Orçamento criando um 'Infinite Marquee' (Ticker Tape).

Regras:
1. Uma faixa de ponta a ponta na tela, com a cor Accent de fundo e texto na cor Dark.
2. O texto será '[DIGITE SUA PALAVRA, EX: EXCLUSIVIDADE • LUXO • RESULTADO]'.
3. Use CSS Keyframes (transform: translateX) para fazer o texto rolar da direita para a esquerda infinitamente, sem quebras ou travamentos. Não use JavaScript para isso."

Prompt 7: O Menu Mobile Fullscreen (Dark Overlay)

"Construa a navegação mobile. É proibido usar o dropdown padrão do Bootstrap.

Quando o cliente clicar no 'Menu' (Hamburger), a tela inteira deve ser coberta por um overlay escuro (backdrop-filter pesado) abrindo com uma transição suave. Os links de navegação devem aparecer em tipografia gigante (Fraunces), centralizados na tela. O botão de fechar deve ser minimalista e elegante no canto superior direito."

Micro-Interações e Motion

Prompt 8: Scroll-Driven Motion (Nativo)

"Atue como o Animador do squad. Queremos um efeito de revelação ao scrollar a página para a Metodologia e os Preços.

Restrição Técnica: Não use bibliotecas (GSAP, Lenis) ou JS. Use puramente CSS Nativo com '@supports (animation-timeline: view())'.
As caixas devem começar com 'opacity: 0' e 'transform: translateY(40px)', e revelar gradativamente enquanto entram na viewport do cliente."

Prompt 9: O Cursor Interativo nos Botões

Faz a "bolinha" do mouse engolir os links.

"Melhore a interação do nosso '.cursor-dot'. Adicione um script JS leve que escute os eventos de 'mouseenter' e 'mouseleave' em todos os botões e links ('a', 'button').

Quando o mouse passar sobre um link, o .cursor-dot deve aumentar de tamanho (scale 3) e sua cor deve ficar semi-transparente (ou inverter as cores do fundo). Isso dará a sensação de um hover magnético de alto padrão."

Prompt 10: Texto de Revelação (Text Reveal)

Para o título gigante da Hero section nascer na tela.

"Aplique um 'Text Reveal Animation' apenas na Headline (H1) da primeira dobra.

Separe o H1 usando tags span com 'overflow: hidden'. O texto interno deve sofrer um 'transform: translateY(100%)' inicial. Ao carregar a página, as palavras devem deslizar de baixo para cima sequencialmente (stagger), durando cerca de 1 segundo e usando um 'cubic-bezier' suave. Forneça o CSS para isso."

Finalização e Limpeza

Prompt 11: O Preloader Minimalista

"Como essa proposta será enviada para clientes High-Ticket, crie uma tela de Loading (Preloader) que dura exatamente 1.5 segundos antes de mostrar o site.

A tela deve ser totalmente preta. No centro, mostre uma contagem de 0% a 100% carregando, usando a fonte Fraunces fina. Ao atingir 100%, o preloader deve deslizar para cima (transform: translateY(-100%)), revelando o site brutalista embaixo."

Prompt 12: O Footer "Manifesto"

"Esqueça rodapés tradicionais com copyright miúdo. Crie um Footer 'Manifesto' ocupando 100vh da tela no final.

Regras:
1. Uma frase final de impacto em tamanho Colossal (clamp(4rem, 15vw, 12rem)), cortando as bordas se necessário.
2. Abaixo dela, um botão gigante para o cliente clicar e aceitar a proposta (acionando o link do WhatsApp).
3. Um botão secundário de 'Baixar PDF da Proposta', usando window.print()."

Prompt 13: O Refinamento de Tipografia (Anti-Bootstrap)

"O design está ficando com cara de template genérico. Reajuste as regras de tipografia:

1. Remova todos os 'text-align: center'. O brutalismo exige alinhamentos secos à esquerda.
2. Aumente drasticamente o tamanho do H1 para 'clamp(3rem, 10vw, 8rem)'.
3. Aumente o letter-spacing nas sub-tags.
4. Garanta que a fonte serifada (Fraunces) esteja sendo aplicada com font-weight 300."

Prompt 14: O Filtro Anti-Slop de Código

"Atue como Editor Sênior. Releia todo o código gerado e remova:
- CSS não utilizado.
- Tags divs desnecessárias (div soup).
- Sombras pesadas (box-shadow) feias. Troque todas por sombras hiper-sutis rgba(0,0,0,0.05).
- Confirme se não há requisições de backend que quebrariam ao hospedar em arquivos estáticos (Surge.sh)."
